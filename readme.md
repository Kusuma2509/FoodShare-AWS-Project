# FoodShare – Cloud-Based Food Sharing Platform

## About the Project

FoodShare is a cloud-based food-sharing website developed to help reduce food wastage by connecting food donors with people in need.

The platform allows users to view available food donations and share details about surplus food. The website is hosted using Amazon Web Services (AWS) S3 static website hosting.

## Objectives

- To reduce food wastage by encouraging food donations.
- To connect food donors with people in need.
- To provide a simple and user-friendly food-sharing platform.
- To understand cloud computing and AWS services.
- To deploy a static website using Amazon S3.

## Technologies Used

- **HTML5:** Used to create the structure and content of the website.
- **CSS3:** Used to design the website layout and appearance.
- **JavaScript:** Used to add interactive features.
- **Amazon S3:** Used to store website files and host the static website.
- **AWS Management Console:** Used to configure the S3 bucket and website hosting.

## Features

- User-friendly homepage.
- View available food donations.
- Donate surplus food by entering food details.
- Search and filter food listings.
- Sort available food listings.
- Interactive website interface.

## AWS Implementation

The website is deployed using Amazon S3 static website hosting.

Implementation steps:

1. Created an S3 bucket.
2. Enabled static website hosting.
3. Uploaded the website files.
4. Configured public access permissions.
5. Added a bucket policy to allow public reading of website files.
6. Accessed the website through the S3 website endpoint.
